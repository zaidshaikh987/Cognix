# COGNIX Framework — Experiment Protocol

To ensure rigorous, reproducible research results, all COGNIX experiments must adhere to the following protocol.

## 1. Experiment Run IDs

Every experiment must generate a unique `run_id` (e.g., `exp_20260907_143022_b8f9a2`). 
All outputs from that experiment must be saved in `results/<run_id>/`.

**Required contents of `results/<run_id>/`**:
- `config.yaml`: The exact `CognixConfig` used.
- `metadata.json`: Environment details (git commit, random seed, dataset, model versions).
- `metrics.json`: Final calculated metrics.
- `predictions.json`: Raw pipeline inputs and outputs (for post-hoc analysis).

## 2. Research Questions (RQs)

For every experiment, the RQ must be explicitly mapped to independent and dependent variables.

### RQ1: Does epistemic uncertainty better detect sensor failure than raw confidence?
- **Independent Variable**: Uncertainty metric used for escalation (Confidence vs Total Entropy vs Epistemic).
- **Dependent Variable**: Selective risk accuracy, AUROC for OOD/failure detection.
- **Stress Condition**: Synthetic noise injection (Camera/LiDAR degradation).

### RQ2: Does epistemic-weighted belief fusion improve robustness under agent disagreement?
- **Independent Variable**: Fusion Strategy (Uniform vs Majority vs Confidence-weighted vs Bayesian vs Epistemic-weighted).
- **Dependent Variable**: Fused accuracy, ECE (Expected Calibration Error).
- **Stress Condition**: Conflicting agent predictions (e.g., Agent A confident but wrong, Agent B less confident but correct).

### RQ3: Can communication overhead be reduced without sacrificing decision safety?
- **Independent Variable**: Communication Policy (All-to-All vs Top-K vs Information-Gain).
- **Dependent Variable**: System accuracy, Risk level, Messages sent (reduction %).
- **Stress Condition**: High baseline uncertainty requiring information seeking.

## 3. Baselines

COGNIX results MUST be compared against standard baselines using the **SAME** dataset and seed.

- **Baseline 1**: Simple Majority Voting (no uncertainty tracking).
- **Baseline 2**: Confidence-Weighted Average.
- **Baseline 3**: Independent Agent (best single agent).
- **Cognix**: Full pipeline (Epistemic-weighted fusion + Escalation).

## 4. Required Reporting Format

Do not report single numbers without context. Use the following format for claims:

| Metric | Target | Baseline (Majority) | COGNIX | Improvement |
|--------|--------|---------------------|--------|-------------|
| System Accuracy | > 90% | 82.3% | 89.1% | +6.8% |
| Comm Overhead | < 50% | 100% | 37% | -63% |
| Escalation Rate | < 10% | N/A | 8.2% | - |

*Note: The above numbers are examples. All final numbers must be generated by code.*
